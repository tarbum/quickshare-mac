# Changelog

## 1.0.5

- Added transport toggles for Bluetooth LE, Wi-Fi LAN, Wi-Fi Hotspot, and Wi-Fi Direct.
- Transport changes now apply without relaunching the app.
- Added a Launch at login option.
- Made the visible device name clearly editable.
- Removed protocol and status details from Settings.
- Wi-Fi is now powered on automatically for Wi-Fi Direct transfers.
- Kept `--no-wifi-lan` working for troubleshooting.
